# Make your first stax

Five minutes, one real piece of work. A stax holds why you are doing it, what done looks like, and the next action.

## Why it matters to you

Tomorrow, 09:00. You open the stax and the next step is already there. No "where was I?", no scrolling back through a chat.

## How to do it

1. Sign up at [dash.heystax.ai](https://dash.heystax.ai).
2. Click **New Stax**. Name it after something real, like `Job Search` or `Kitchen Renovation`. Not "test".
3. Add three next actions. Each one is a step you could start right now.
4. In **Project Settings**, write one line on why (the mission) and one goal you could see from outside.
5. Do one action and tick it.
6. Close the tab. Open the stax tomorrow and start on the next one.

| Not this | This |
|---|---|
| Work on the kitchen | Measure the gap between the fridge and the counter |
| Deal with the proposal | Email Marcus the draft proposal, subject line only |
| Sort out the migration | Run the migration script on staging and read the logs |

## Bring someone in

Make a second stax for something you share, like a house move. Add the other person to it.

Now you both see the same next actions, each with a name on it. "Can you check if we need to book the surveyor?" stops living in WhatsApp. It is a card with an owner.

Keep the stax's tabs with the [TabStax extension](surfaces/tabstax-extension): one click opens them all.
